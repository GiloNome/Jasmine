# Attendance Tracking System

A web-based attendance tracking system designed to efficiently manage and record student attendance.

## Features

- Manage student attendance
- Real-time tracking
- User-friendly interface
- MySQL database integration

## Setup Instructions

1. Clone the repository.
2. Set up a PHP server (e.g., XAMPP, WAMP, or MAMP).
3. Import the database schema from `attendance_system.sql`.
4. Configure the database connection in `src/db_config.php` using your MySQL credentials.
5. Open a web browser and navigate to the project folder to access the system.

## Project Structure

- `src/` – Contains the main application files:
  - `ATS.html` – Main user interface
  - `api.php` – Backend API endpoints
  - `script.js` – Frontend logic
  - `styles.css` – Styling file

## Requirements

- PHP server (version 7.x or above recommended)
- MySQL database
- Modern web browser
